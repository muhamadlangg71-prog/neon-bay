Neon Bay is an open-world crime game in the spirit of GTA 6: explore a sun-soaked coastal city on foot and by car, steal cars, dodge traffic and pedestrians, climb a wanted level with police chases, fight through six story missions, and track it all on a HUD with a minimap. Playable in a desktop browser from static files.

## Run it

```sh
python3 -m http.server 8000 --directory game
```
